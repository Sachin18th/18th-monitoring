## TL;DR — Headline

This is a **modular monolith MVP with a real Postgres/Prisma core and a genuinely good Next.js dashboard**, wrapped in documentation that describes a **production-grade distributed SaaS platform**. The gap between doc and code is large but uneven:

- **Real & solid:** relational schema + indexing, 3 commerce connectors (Shopify/Adobe/BigCommerce) doing real REST polling, ingestion→validation→dedup pipeline, the RUM/telemetry SDK + collector, auth (scrypt + server sessions), tenant-isolation middleware, the dashboard UI (~28 real routes).
- **Illusory / scaffolding:** "Kafka" is an in-process EventEmitter; canonical data + KPIs default to an in-memory store; 3 of 5 named backend apps are empty folders; the 12-method connector contract barely exists; all non-commerce connectors are metadata-only.
- **Security-critical gaps:** webhook endpoint is unauthenticated (HMAC code is dead), connector credentials stored as plaintext, no query-level tenant filtering (cross-tenant leak risk), no MFA, hardcoded `Demo@1234!` superadmin.

Key evidence files: `packages/db/prisma/schema.prisma`, `apps/api/src/services/*-order-sync.service.ts`, `apps/api/src/services/ingestion-pipeline.service.ts`, `packages/streaming/src/memory-bus.ts`, `packages/db/src/adapters/in-memory.adapter.js`, `packages/rum-sdk/src/index.ts`, `apps/api/src/controllers/webhook.controller.ts`, `apps/api/src/controllers/integration.controller.ts`.
